#####################
3I/ATLAS image stamps
#####################

DOI: `zenodo.org/records/19244429 <https://zenodo.org/records/19244429>`_

Stamps of the commissioning images that include 3I/ATLAS, as presented in `Chandler et al. (2026) <https://ui.adsabs.harvard.edu/abs/2025arXiv250713409C/abstract>`_.

Access
======

Copies of these stamps are available via the Rubin Science Platform as demonstrated in the 3I/ATLAS commissioning tutorial notebook (see the :doc:`/tutorials/index`).

Description
===========

Small image cutouts, centered on the JPL Horizons coordinates for 3I/ATLAS.

Caveats
-------

* Commissioning images may have (very) degraded image quality.
* The pixel value units are in counts, not calibrated flux (nJy) as is standard for Rubin images.
* Headers contain the WCS only.
* Not all stamps are exactly centered on 3I/ATLAS.
* The photometry reported in Chandler et al. (2026) was performed on difference images, which are not available.
